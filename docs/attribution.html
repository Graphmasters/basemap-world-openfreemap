5. Sprites and fonts: hosted by BKG

Map symbols (sprite) and font glyphs are loaded directly from BKG servers at request time. This repository does not copy or redistribute them:

  • Sprite: https://sgx.geodatenzentrum.de/gdz_basemapde_vektor/sprites/v2/bm_web_col_sprite
  • Glyphs: https://sgx.geodatenzentrum.de/gdz_basemapde_vektor/fonts/v2/{fontstack}/{range}.pbf (Noto Sans and Roboto; both font families are under open font licences)

Using them is subject to BKG's terms of use. If those endpoints change or become unavailable, symbols and labels will stop rendering.

6. Changes to the original style

  • Removed all layers that use the Germany-only BKG source (smarttiles_de, BKG's own schema). In Germany the map therefore shows the world rendering rather than BKG's detailed national cartography.
  • Replaced the world source (smarttiles_wld) with OpenFreeMap vector tiles. Layer paint, layout, zoom ranges and order are unchanged.
  • Removed filter clauses on the BKG-only attribute klasse (building classes).
  • Replaced the style name, id, metadata and source attribution.

No BKG vector-tile data or BKG geodata are used. BKG is the author of the map design, not the provider of the road network or other map content shown.
