basemap.world for OpenFreeMap

Unofficial adaptation of the basemap.world Web Vektor cartography (BKG) that renders only OpenFreeMap vector tiles. Not an official BKG or basemap.de product.

z – · –

Use it in MapLibre GL JS 
const styleBase = 'https://graphmasters.github.io/basemap-world-openfreemap';
const map = new maplibregl.Map({
  container: 'map',
  style: `${styleBase}/style.json`,
});

The style's source attribution carries every credit, including the BKG notice, and links to the full credits page. Do not add your own style credit; it would appear twice.
